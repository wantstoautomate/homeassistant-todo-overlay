# Home Assistant Todo Overlay

An enhanced overlay for Home Assistant's Todo entities.

## Planned Features

- Hierarchical tasks
- Tags
- Saved views
- Task metadata
- Archived tasks
- Custom ordering
- Rich Lovelace card

## Architecture

- Backend: Home Assistant custom integration (Python)
- Frontend: Custom Lovelace card (TypeScript/Lit)
- Storage: Home Assistant storage helpers

## Development

This repository contains the custom integration, frontend card and automated tests.
